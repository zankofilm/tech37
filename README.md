# مدرسه‌یار — اپ Native معلم Android 4.1.2

## 4.1.2 — اصلاح نمایش تصاویر مخزن سؤال
- پشتیبانی از تصویرهای ذخیره‌شده روی هاست با مسیر نسبی و URL هم‌دامنه، علاوه بر تصویرهای Base64.
- اصلاح مسیر قدیمی `/student/media/question-images/...` برای نصب cPanel زیر `/app/`؛ مسیر نهایی به `/app/student/media/question-images/...` تبدیل می‌شود و از دوباره‌افزایی `/app/` جلوگیری می‌شود.
- دریافت تصویر فقط از HTTPS و همان دامنه، با توکن نشست در صورت نیاز، محدودیت حجم ۳ مگابایت و کنترل نوع محتوای تصویر.
- شناسایی نام‌های قدیمی/جایگزین فیلد تصویر در پاسخ API (از جمله `imageUrl`، `image_url`، `imagePath` و `image`).
- نمایش وضعیت بارگذاری تصویر و پیام خطای روشن‌تر؛ اصلاح نمایش در مخزن، جزئیات آزمون و آزمون‌ساز.
- افزودن تست مسیر cPanel، جلوگیری از دوباره‌افزایی BasePath، رد دامنه خارجی و مسیر traversal.
- نسخه 4.1.2، Version Code 30.

گزارش کامل تغییرات: `RELEASE-NOTES-4.1.2-QUESTION-IMAGES-FA.md`.

این پروژه اپلیکیشن Native اندروید معلم مدرسه‌یار با Kotlin و Jetpack Compose است و مستقیماً از APIهای هاست استفاده می‌کند؛ WebView نیست.

## API و امنیت
- مسیرهای API هاست تغییر نکرده‌اند.
- سؤال تأییدشده مخزن در آزمون به‌صورت کپی قابل ویرایش استفاده می‌شود و رکورد اصلی تغییر نمی‌کند.
- هیچ آمار یا عملیات پشتیبانی‌نشده به شکل نمایشی جعل نشده است.
- توکن و نشست از سازوکار امن موجود پروژه استفاده می‌کنند.

## Build با GitHub Actions
Workflow در `.github/workflows/build-apk.yml` از Java 17، Gradle 8.9 و Android SDK 35 استفاده می‌کند.
1. فایل‌ها را در ریشه مخزن GitHub جایگزین کنید.
2. Commit و Push انجام دهید یا از Actions گزینه `Build Madreseyar Teacher APK` را دستی اجرا کنید.
3. در صورت موفقیت، فایل `Madreseyar-Teacher-APK` از Artifacts دریافت می‌شود.
