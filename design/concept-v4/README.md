# مدرسه‌یار معلم — طرح مفهومی نسخه 4

این چهار تصویر مرجع بصری هستند: داشبورد، کلاس‌ها و دانش‌آموزان، مخزن سؤال/آزمون‌ساز و گزارش‌ها.

تصاویر، ماکاپ تولیدشده برای توافق روی جهت طراحی‌اند و خودشان کد یا خروجی واقعی اپ نیستند. رابط واقعی با Jetpack Compose در سورس پیاده‌سازی شده و اعداد و فهرست‌ها از داده‌های API موجود تغذیه می‌شوند؛ مواردی که داده ندارند به‌صورت ساختگی پر نشده‌اند.
