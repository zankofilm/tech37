# وضعیت پیاده‌سازی طرح مرجع

این چهار تصویر مرجع بصری نسخه 4.1.0 هستند. رابط واقعی به‌صورت Native و قابل تعامل با Jetpack Compose پیاده شده است؛ تصاویر ماکاپ به‌عنوان صفحه ثابت یا پس‌زمینه استفاده نشده‌اند.

- `dashboard-concept.png` ← `HomeScreen` و `TeacherHeroHeader`
- `classes-concept.png` ← `ClassesScreen`
- `question-bank-concept.png` ← `QuestionBankNativeScreen`
- `reports-concept.png` ← `ContinuousReportsNativeScreen`

به دلیل اینکه بعضی اطلاعات مانند عکس پروفایل، رتبه‌بندی دانش‌آموزان، روند هفتگی نمرات و خروجی PDF/Excel در APIهای در دسترس این اپ وجود ندارد، این موارد با داده ساختگی نمایش داده نمی‌شوند. اجزای آماری از داده واقعی سرور تغذیه می‌شوند.
